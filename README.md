# 掌控生产力：Better Ideas 方法论完全指南

基于 Joey Schweitzer 的 Better Ideas YouTube 频道（2017-2026）120+ 个视频的深度提炼与系统化整合。

## 这本书是什么

Better Ideas 是一个专注于生产力、习惯、心理和生活设计的 YouTube 频道，由 Joey Schweitzer 创立于 2017 年。这本书将频道 8 年间最核心的方法论提炼成一个统一的知识系统，以中文呈现。

## 本书结构

### 第一部分：理解你的大脑
- 忙碌 vs 真实生产力的本质区别
- 拖延症的心理机制与破解之道
- 过度刺激对专注力的系统性破坏
- 意志力的真实工作方式

### 第二部分：重塑身份认同
- 身份认同作为行为改变的根本杠杆
- 舒适区的动态性质与成长区的实践
- 自我叙事的力量与重写方法

### 第三部分：构建生产力系统
- 环境设计的科学与实践
- 习惯构建从抵抗到自动化的完整路径
- 游戏化思维在真实生活中的应用

### 第四部分：长期复利与人生设计
- 微小优势的复利效应
- 晨间例程的设计原则
- 困顿期的重建艺术
- 设计你真正想要的生活

## 如何阅读

这本书被设计为既可以从头到尾线性阅读，也可以根据你当前最迫切的需求直接跳到相关章节。

如果你不知道从哪里开始，推荐先阅读**系统地图**，它提供了整本书方法论的鸟瞰视角和诊断工具，帮助你识别你最需要关注的领域。

## 快速开始

1. 阅读[前言](preface.md)了解这本书的核心主张
2. 使用[系统地图](system-map.md)诊断你的情况
3. 从最相关的章节开始
